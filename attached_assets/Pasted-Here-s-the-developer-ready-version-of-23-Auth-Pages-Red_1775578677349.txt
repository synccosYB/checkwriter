#23 — Auth Pages Redesign

Objective

Redesign all authentication-related pages in the Synccos Check Writer app so they fully match the new corporate/professional design system and feel like a polished premium fintech sign-in experience.

This task is focused on the full authentication surface area: login, registration, password reset, verification, MFA, profile completion, organization creation, and related public/legal pages.

What & Why

The current auth experience appears to rely on basic Bootstrap-style form presentation with a static banner treatment and inconsistent visual hierarchy. Even if the flows work, they do not yet communicate the level of professionalism, trust, and product maturity expected from a financial application.

Authentication is one of the most important trust touchpoints in the product. It should feel:

secure
clean
premium
modern
professional
easy to understand
visually calm

The redesign should align auth pages to the new brand system established in the layout/theme overhaul:

navy/slate professional palette
warm accent highlights
clean white form surfaces
strong typography hierarchy
refined spacing
modern card-based form design
polished CTA hierarchy
responsive layout behavior

This is a visual redesign only. Existing auth flows, validation, submission behavior, and API connections must remain unchanged.

Design Goals
1. Trust First

These pages should immediately communicate:

security
professionalism
clarity
product maturity

Avoid anything that feels:

playful
generic
overly colorful
cluttered
template-like
2. One Auth System

All auth-related pages should feel like part of one cohesive family.

That means consistency across:

card treatment
button hierarchy
form spacing
labels/helper text
headings/subheadings
legal/support links
secondary actions
3. Clear Action Hierarchy

Each auth page should make the primary next step obvious.

Examples:

Login → Sign in
Sign Up → Create account
Forgot Password → Send reset link
OTP → Verify code
New Password → Set new password

Secondary links/actions should remain visible, but not compete visually with the primary CTA.

4. Premium Fintech Tone

The auth experience should feel closer to:

Mercury
Bill.com
Ramp
modern banking SaaS
than a default admin template.

That means:

generous whitespace
clean cards/panels
strong typography
restrained color usage
subtle shadows
thoughtful spacing
polished form treatment
Visual Direction
Auth Layout Structure

Use the redesigned AuthLayout as the base shell for all relevant auth pages.

Recommended Pattern

A split-screen or premium single-panel auth layout depending on the page:

Left panel: branded visual area with navy gradient/brand message/illustration/pattern
Right panel: clean white form panel or centered auth card

For simple reset/verification/legal pages, a simplified centered card variant may also be used if that is cleaner and still consistent.

Left Panel Direction
navy/slate gradient or brand visual treatment
white text
subtle geometric pattern or overlay
concise trust/value messaging
product branding/logo placement

This should feel professional and established, not decorative for its own sake.

Right Panel Direction
white or subtle neutral surface
centered form card or structured form container
strong title and supporting copy
consistent input/button spacing
clear helper/error states
