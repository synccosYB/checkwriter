#22 — Design System & Layout Overhaul

Objective

Create and apply a centralized corporate-grade design system for the Synccos Check Writer web app, then use that system to restyle all shared layouts and reusable UI primitives without changing application logic.

This is a visual foundation task. It should establish a polished, consistent, professional fintech identity across the app so that all later page-level redesigns can build on top of it.

What & Why

The current UI is visually inconsistent. It mixes:

Bootstrap utility styling
inline MUI styles
legacy CSS files
inconsistent spacing, radii, shadows, and typography
older green/teal colors that do not reflect a strong financial/corporate brand

This task replaces that fragmented styling approach with a single theme-driven design system inspired by modern corporate fintech dashboards like QuickBooks, Bill.com, Mercury, and similar B2B SaaS tools.

The new direction should feel:

trustworthy
corporate
premium
modern
spacious
clear
efficient

The desired visual language is:

navy / slate blue primary brand
warm amber accent
cool gray application backgrounds
white cards and surfaces
sharp typography hierarchy using Inter
subtle depth via shadows, not heavy borders
refined, calm UI rather than loud or playful
Core Design Principles
Theme first
Styling should come primarily from a centralized MUI theme, not scattered CSS overrides or inline sx patches.
Shared layouts first
Focus on layout shell and shared components before touching individual pages.
Professional fintech tone
The app should feel like a serious financial workspace, not a generic admin panel.
Consistency over one-off styling
Buttons, cards, drawers, inputs, tables, modals, and navigation should all follow the same visual system.
No logic changes
Existing features, data flow, role behavior, routing, API calls, and component logic must remain intact.
