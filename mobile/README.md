# Synccos Check Writer — Mobile Build Guide

This directory contains the native iOS and Android projects generated by [Capacitor](https://capacitorjs.com/). The web app (React) is packaged into these native shells to produce App Store and Google Play-ready binaries.

---

## Prerequisites

| Tool | Version | Purpose |
|------|---------|---------|
| Node.js | 18+ | Build the React app and run Capacitor CLI |
| npm | 9+ | Package manager |
| Xcode | 15+ | Build and submit the iOS app (macOS only) |
| Android Studio | Flamingo+ | Build and submit the Android app |
| CocoaPods | 1.12+ | iOS dependency manager (`sudo gem install cocoapods`) |
| Java JDK | 17+ | Required by Android Gradle toolchain |

---

## Building & Syncing

Run the following command from the **project root** to build the React app and sync the latest web assets into both native projects:

```bash
npm run mobile:build
```

This is equivalent to:

```bash
cd client && npm run build && npx cap sync
```

> **Note:** Always run `npm run mobile:build` before opening Xcode or Android Studio so the native projects contain the most recent web code.

---

## iOS — Open in Xcode

After running `npm run mobile:build`:

1. Install CocoaPods dependencies (first time or after adding plugins):
   ```bash
   cd mobile/ios/App && pod install
   ```
2. Open the workspace in Xcode:
   ```bash
   open mobile/ios/App/App.xcworkspace
   ```
   > Open the `.xcworkspace` file, **not** the `.xcodeproj` file, to include CocoaPods.
3. Select your target device or simulator in the Xcode toolbar.
4. Press **⌘R** (or click the Run button) to build and launch.

---

## Android — Open in Android Studio

After running `npm run mobile:build`:

1. Open Android Studio.
2. Choose **File → Open** and select the `mobile/android/` directory.
3. Wait for Gradle sync to complete.
4. Select a device or emulator from the device dropdown.
5. Press the **Run** button (green triangle).

---

## App Store Submission (iOS)

1. Log in to [App Store Connect](https://appstoreconnect.apple.com/) with your Apple Developer account.
2. In Xcode, set your **Team** and **Bundle Identifier** (`com.synccos.checkwriter`) under *Signing & Capabilities*.
3. Update the version and build number in Xcode's *General* tab.
4. Select **Any iOS Device (arm64)** as the build target.
5. Go to **Product → Archive** to build a release archive.
6. In the **Organizer** window, click **Distribute App** and follow the App Store Connect upload wizard.
7. Complete the app listing, screenshots, and review information in App Store Connect, then submit for review.

Official guide: https://developer.apple.com/documentation/xcode/distributing-your-app-for-beta-testing-and-releases

---

## Google Play Submission (Android)

1. Log in to the [Google Play Console](https://play.google.com/console).
2. In Android Studio, go to **Build → Generate Signed Bundle / APK**.
3. Choose **Android App Bundle** (recommended) or **APK**, then create or select your keystore.
4. Build a **Release** variant.
5. In the Play Console, create a new release under your chosen track (Internal, Alpha, Beta, or Production), upload the `.aab` file, and complete the store listing.
6. Submit for review.

Official guide: https://developer.android.com/studio/publish

## Capacitor Configuration

The Capacitor configuration lives at `client/capacitor.config.ts`. Key settings:

| Setting | Value |
|---------|-------|
| App ID | `com.synccos.checkwriter` |
| App Name | `Synccos Check Writer` |
| Web Dir | `build` (React production build output) |
| iOS project path | `../mobile/ios` |
| Android project path | `../mobile/android` |

**Development (live-reload against a running dev server):**

Set the `CAPACITOR_DEV_SERVER_URL` environment variable before syncing to point the native app at your running dev server:

```bash
CAPACITOR_DEV_SERVER_URL=https://your-dev-server.example.com npm run mobile:build
```

The config reads this variable automatically and injects `server.url` into the Capacitor config at sync time. When the variable is not set (production builds), the app uses the bundled web assets with relative paths — no remote URL dependency.

**Production builds:**

Do not set `CAPACITOR_DEV_SERVER_URL`. Run `npm run mobile:build` normally; the app loads from the bundled `build/` assets.

## Troubleshooting

- **"web assets directory must contain index.html"** — Run `npm run mobile:build` first to generate the React build.
- **CocoaPods not found** — Install with `sudo gem install cocoapods`, then re-run `pod install`.
- **Gradle sync fails** — Ensure JDK 17+ is installed and `JAVA_HOME` is set correctly.
- **CORS errors on device** — The API server accepts all origins by default. If you see CORS errors, confirm `api/src/index.ts` has `callback(null, true)` in the CORS origin handler.
